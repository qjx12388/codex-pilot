# codex-pilot

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Русский](README.ru.md) | [Español](README.es.md) | **हिन्दी**

Codex के लिए एक सलाहकार skill: यह आपके स्वाभाविक भाषा में लिखे अनुरोधों को Codex / codex-cli के सबसे अच्छे उपयोग तरीके में बदलता है — और फिर उन्हें तुरंत स्वयं ही पूरा करता है।

इसमें एक ऑफ़लाइन नॉलेज पैक शामिल है (संपीड़ित आर्काइव के रूप में वितरित, इंस्टॉलेशन के समय अपने-आप खुल जाता है)। जब Codex यह skill लोड करता है, तो वह पहले विषय-रूटिंग तालिका के माध्यम से नॉलेज बेस देखता है, "सर्वोत्तम उपयोग योजना" प्रस्तुत करता है (कौन-सी सुविधा / कमांड / कॉन्फ़िगरेशन / प्रॉम्प्ट शैली उपयोग करनी है, संदर्भ सहित), और फिर बिना रुके आपका कार्य पूरा करता है।

## इंस्टॉलेशन

```bash
git clone https://github.com/qjx12388/codex-pilot.git
cd codex-pilot
./scripts/install.sh          # सिमलिंक इंस्टॉल (अनुशंसित; रिपॉज़िटरी में बदलाव तुरंत प्रभावी)
./scripts/install.sh --copy   # या स्वतंत्र कॉपी
```

इंस्टॉलर बंडल किए गए नॉलेज पैक को अपने-आप खोल देता है। इंस्टॉलेशन के बाद skill `~/.agents/skills/codex-pilot/` में रहता है और किसी भी प्रोजेक्ट में Codex CLI, IDE एक्सटेंशन और ChatGPT डेस्कटॉप ऐप में काम करता है (दिखाई न दे तो Codex पुनः आरंभ करें)।

## उपयोग

- स्पष्ट ट्रिगर: Codex में `$codex-pilot` टाइप करें, जैसे `$codex-pilot CI में codex कैसे चलाऊँ?`
- अंतर्निहित ट्रिगर: सीधे उपयोग-संबंधी प्रश्न पूछें, जैसे "codex के sandbox मोड कौन-से हैं और उन्हें कैसे कॉन्फ़िगर करें?"
- योजना बताने के बाद Codex आपका असली कार्य तुरंत करता है (जोखिम भरे ऑपरेशन पहले आपकी पुष्टि मांगते हैं)।

## रिपॉज़िटरी संरचना

```
SKILL.md              skill एंट्री पॉइंट: ट्रिगर विवरण + वर्कफ़्लो + विषय रूटिंग तालिका
data/knowledge.pack   बंडल किया गया ऑफ़लाइन नॉलेज पैक (इंस्टॉलेशन पर knowledge/ में खुलता है)
scripts/              install.sh इंस्टॉलेशन हेतु; update-knowledge.sh मेंटेनर्स के लिए पैक अपडेट हेतु
```

`data/knowledge.pack` एक बाइनरी आर्काइव है जिसमें तृतीय-पक्ष दस्तावेज़ हैं; उसकी सामग्री के अधिकार संबंधित लेखकों के पास रहते हैं। केवल आर्काइव ही वितरित किया जाता है — खोला गया `knowledge/` डायरेक्टरी ट्रैक नहीं होती (देखें `.gitignore`)।
