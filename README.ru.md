# codex-pilot

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | **Русский** | [Español](README.es.md) | [हिन्दी](README.hi.md)

Skill-консультант для Codex: превращает ваши запросы на естественном языке в оптимальный способ использования Codex / codex-cli — и сразу выполняет их автономно.

В комплекте офлайн-база знаний (распространяется в виде архива, автоматически распаковывается при установке). Загрузив этот skill, Codex сначала обращается к базе знаний через таблицу тематической маршрутизации, выдаёт «оптимальный план использования» (какую функцию / команду / настройку / стиль промпта применить, со ссылками на источники), а затем без пауз выполняет вашу задачу.

## Установка

```bash
git clone https://github.com/qjx12388/codex-pilot.git
cd codex-pilot
./scripts/install.sh          # установка через симлинк (рекомендуется; изменения в репозитории действуют сразу)
./scripts/install.sh --copy   # или автономная копия
```

Скрипт установки автоматически распаковывает встроенный пакет знаний. После установки skill находится в `~/.agents/skills/codex-pilot/` и работает в Codex CLI, расширении IDE и десктопном приложении ChatGPT — в любом проекте (перезапустите Codex, если skill не появился).

## Использование

- Явный вызов: введите `$codex-pilot` в Codex, например `$codex-pilot как запустить codex в CI?`
- Неявный вызов: просто задайте вопрос об использовании, например «какие режимы песочницы есть у codex и как их настроить?»
- После вывода плана Codex немедленно выполняет вашу задачу (рискованные операции требуют подтверждения).

## Структура репозитория

```
SKILL.md              точка входа skill: описание триггеров + рабочий процесс + таблица маршрутизации
data/knowledge.pack   встроенный офлайн-пакет знаний (распаковывается в knowledge/ при установке)
scripts/              install.sh — установка; update-knowledge.sh — обновление пакета для мейнтейнеров
```

`data/knowledge.pack` — бинарный архив, содержащий стороннюю документацию; права на её содержимое принадлежат соответствующим авторам. Распространяется только архив — распакованный каталог `knowledge/` не отслеживается (см. `.gitignore`).
